# Sanitized experimental archive

This branch preserves the widget/MCP/browser feasibility work, tests and evidence.
It is not a working production deployment. Personal conversation URLs, account
identifiers, deployment domains, tunnel IDs and local home paths have been replaced
with non-operational examples. The original unredacted snapshot is retained only
in a private local rollback bundle, never included in the push.

Opaque event/session identifiers in the chronology are redacted, so use sequence
and timestamps to distinguish experiments. Live conclusions are unchanged:
manual baseline observed; remote-event wake not observed; NO-GO in tested conditions.
No account email, browser profile, OAuth token or runtime database is provided.
